System audio recorder

Soundcard Recorder

Version 1.0 · macOS 14.2+ · Universal download

Records your Mac's system audio — every sound the computer plays — and never opens the microphone. Perfect for saving a stream, a podcast, a call you're allowed to keep, or a track you can't download.

  • MP3, AAC, FLAC and ALAC with selectable bitrates
  • Live level meter with a stereo balance readout
  • ⌘R record, ⌘P pause, ⌘L reveal the last take
  • Captures even with headphones plugged in
  • Tells you when a saved file came out silent
  • Never overwrites a file with the same name

Live radio + recorder

Dance Box Radio

Version 3.0.0 · arm64 · macOS 14.4+

Live dance music radio from 98 countries, with a one-click recorder that keeps exactly what you're hearing. Native SwiftUI, no accounts, no telemetry — the station list ships inside the app so browsing works offline.

  • 535 live dance streams from 98 countries
  • Browse by country or genre — house, techno, trance, D&B, garage and more
  • REC writes a 192 kbps AAC clip to ~/Music/DanceBox
  • Recordings tab to play, reveal, convert or bin
  • Favourites, recent stations and a play history
  • Media keys and Now Playing support

Blu-ray & DVD ripper

RipKit

Version 1.0 · arm64 · macOS 12.0+

Backs up Blu-ray and DVD discs to MKV with your own decryption keys, then compresses the result with bundled HandBrake and ffmpeg. Everything it needs ships inside the app — no Homebrew, no installs.

  • makemkvcon, HandBrakeCLI and ffmpeg bundled inside
  • Your keydb.cfg, .dvdcss keys and licence key, saved and backed up
  • Live rip progress bar with retry if the drive drops off USB
  • Rips to a per-disc folder with the MakeMKV log kept beside it
  • x265 compression with quality, audio and subtitle options

Formats

What Soundcard Recorder writes.

Pick a format and bitrate before you hit record. MP3 is written live by a bundled ffmpeg; everything else is encoded natively by macOS.

FormatFileQualityNotes
MP3.mp3320 kbps down to 96Written live; also 256 / 224 / 192 / 160 / 128 / 96 kbps
ALAC.m4aLosslessApple Lossless in an .m4a container
FLAC.flacLosslessLossless, widely playable
AAC.m4a256 kbps defaultAlso 320 / 192 / 160 / 128 / 96 / 64 kbps
Recording comes out silent? Open System Settings ▸ Privacy & Security ▸ Screen & System Audio Recording and allow the app. Silence is captured as silence, so if nothing was playing you'll get a quiet file — and the app tells you when that happens.
Installing

Three steps, about a minute.

The builds are ad-hoc signed rather than notarised, so the first launch on another Mac needs one extra click.

Download the DMG

Grab any app above. The disk image contains the app — drag it to Applications.

Drag it to Applications

Open the DMG and drag the app onto the Applications folder in the window, then eject the disk.

Open it

Double-click the app. If macOS blocks it, right-click ▸ Open, or run xattr -dr com.apple.quarantine /Applications/DanceBox.app in Terminal.

Requirements: Soundcard Recorder needs macOS 14.2 or newer. Dance Box Radio needs macOS 14.4 or newer on an Apple silicon (arm64) Mac. RipKit needs macOS 12.0 or newer on Apple silicon. Neither audio app opens the microphone.
