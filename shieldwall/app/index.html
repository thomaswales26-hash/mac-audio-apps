Browsers require you to approve extensions yourself. Shieldwall reveals the correct folder and gives you the exact steps; it never changes browser policy behind your back.

Firefox Manifest V3 package

Not marked installed

  3. Choose Load Temporary Add-on and select manifest.json.
Why installation is manual

Chrome Web Store and Firefox Add-ons signing are separate publishing processes. This package includes inspectable source extensions, but macOS apps cannot silently install them into your browser.

Privacy by design

Your browsing history never enters this app.

Shieldwall stores only the browser installation checkmarks you set in this controller. Protection settings, site allowlists, and block counters stay inside each browser profile.

No account

No sign-in, cloud sync, advertising identifier, or analytics SDK.

No HTTPS interception

Shieldwall does not install a root certificate or inspect passwords and private page content.

Browser-native filtering

Network requests are blocked with declarative browser rules rather than a man-in-the-middle proxy.

Settings stay local

The controller writes one small JSON file in its macOS application-data folder.
